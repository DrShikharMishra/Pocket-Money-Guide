# Pocket Money Guide – Web Preview

This folder contains a static web demo of the app UI.

## View it live

Once GitHub Pages is enabled, the demo will be available at:

**https://drshikharmishra.github.io/Pocket-Money-Guide/**

## How to enable GitHub Pages

1. Go to the repository → **Settings** → **Pages**
2. Under **Source**, choose **Deploy from a branch**
3. Select branch: `main`
4. Select folder: `/docs`
5. Click **Save**

After 1–2 minutes the site will be live.
